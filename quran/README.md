# القرآن الكريم — المصحف الإلكتروني

موقع مصحف إلكتروني عربي يعمل على GitHub Pages، بواجهة RTL وتصميم متجاوب.

## التشغيل
افتح `index.html` عبر خادم HTTPS أو GitHub Pages. لا تعتمد على فتح الملف مباشرة لأن Service Worker يحتاج HTTPS أو localhost.

## مصادر البيانات
- نص القرآن بالرسم العثماني، وفهرس السور، والصفحات، والأجزاء، والأحزاب، والبحث: [AlQuran Cloud API](https://alquran.cloud/api).
- التلاوات الصوتية تُطلب عند الضغط على زر الاستماع، ولا يتم تحميلها تلقائيًا.
- الخط العربي: Amiri Quran / Amiri من Google Fonts.

## الوظائف
- فهرس السور الـ114 مع البحث والتصفية.
- قراءة السور بالنص العثماني كما تعيده واجهة البيانات.
- فواصل آيات زخرفية مرسومة SVG مدمجة داخل CSS، مع رقم الآية.
- الاستماع للسورة واختيار القارئ.
- التنقل بصفحات المصحف (1–604)، والأجزاء (1–30)، وأرباع الأحزاب (1–240).
- البحث في نص القرآن.
- حفظ آخر موضع قراءة والمفضلة والإعدادات محليًا.
- PWA وتخزين ملفات التطبيق وواجهات API التي تمت زيارتها.
- زر تنزيل نص السور الـ114 إلى IndexedDB للاستخدام دون اتصال بعد اكتمال التنزيل.

## حدود يجب معرفتها
- لا يتم الادعاء بأن جميع صفحات النص متاحة دون إنترنت قبل تنزيلها؛ زر التنزيل يحفظ نص السور كاملة على الجهاز.
- ملفات الصوت لا تُنزّل تلقائيًا ولا تُحفظ للاستخدام دون اتصال.
- خط Amiri Quran بديل متاح عبر الإنترنت، ولم يتم تضمين خط مصحف المدينة KFGQPC المرخّص محليًا.
- زخرفة نهاية الآية SVG زخرفة مرسومة بالواجهة وليست صورة مطابقة حرفيًا لعلامة مصحف المدينة.
- دقة تقسيم الصفحات والأجزاء والأحزاب تعتمد على البيانات التي تعيدها AlQuran Cloud.
